# ClawMuse 1.0.1

## Fixed
- **Updates.** Windows now updates itself: the new version downloads in the background and
  installs when you quit or click **Install update** in Settings (tested from 1.0.0 → 1.0.1
  on a clean PC). On Mac, a 1.0.1 downloaded before 26 September 2026 is not Developer
  ID-signed, and macOS only installs updates in place for signed apps, so it checks for updates,
  tells you once per version, and **Settings → Download 1.0.x** opens the right installer. Your
  chats and settings stay.
- **Signed and notarized on macOS** (updated 26 September 2026). The Mac downloads are now signed
  with an Apple Developer ID and notarized by Apple: no more "Apple could not verify" or
  **Open Anyway**, and a signed install updates itself in place from the next version, like
  Windows. Reinstall from [clawmuse.app/download](https://clawmuse.app/download/) to switch.
- **A sent message no longer disappears** while ClawMuse works on a long reply.
- **Replies after a tool step no longer show twice.**
- **First launch on slower PCs** no longer fails its configuration check while Windows scans
  the freshly unpacked runtime.

## Added
- **ClawMuse changes its own avatar.** Ask it ("change your avatar", "make it better") and it
  picks a new look; or edit it yourself from the status panel's **Identity** tab or
  Settings → your agent.
- **New logo**: a red claw-shaped C holding a spark.
